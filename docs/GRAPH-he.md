# גרף הקמפוס (כלי פנימי)

פתח `graph.html` (למשל `http://localhost:8080/graph.html` אחרי `npm run serve`, או `…/idea1/graph.html` באתר).
הדף לא מקושר מהאתר, מסומן `noindex`, ונועד לעבודה פנימית: להבין את הקמפוס כרשת, לראות איפה חסר מידע, ולבדוק מסלולים.

## איך קוראים את הגרף

| מה רואים | מה זה אומר |
|---|---|
| **צומת** | מקום שבו בן אדם עוצר, מחליט או מזהה: מרפאה/מכון, חדר, לובי, מעלית/מדרגות, **קומה** (כל קומה היא צומת), עמדת מודיעין/משרד, כניסה לבניין, חניה, צומת כבישים גדול |
| **צבע הצומת** | סוג: כחול = מרפאה/מכון · תכלת = חדר · סגול (מעוין) = מעלית · סגול בהיר = מדרגות · כתום = משרד/מודיעין · טורקיז = לובי · אפור = מסדרון/אזור · כהה (ריבוע) = קומה · ירוק = כניסה · צהוב (ריבוע) = חניה · אפור-כחול = צומת/כביש · ורוד = ציון דרך (עגלת קפה, חנות) |
| **גודל הצומת** | **חשיבות ברשת** = מרכזיות ביניים (betweenness): כמה מהמסלולים הקצרים בין זוגות צמתים עוברים דרכו. מסדרון ראשי, לובי וקומת חנויות גדולים; חדר בקצה קטן |
| **קו** | מסדרון, מעבר בין בניינים, יציאה מקומה (המעלית ← הקומה), מדרגות, מסוע, כביש, שביל, חיבור דלת↔לובי. **המשקל** הוא זמן הליכה בשניות (לחיצה על קו מציגה אותו; בזום גבוה או ליד צומת נבחר מוצגות כל המספרים) |
| **קו רציף** | נמדד מגיאומטריה אמיתית של OSM |
| **קו מקווקו** | משקל **משוער** (אף אחד לא מדד) – כאן צריך לתקן בשטח |
| **קו מנוקד כתום** | קישור **לא מאומת** (משוער מהטקסט) – לא נחשב כמעבר פנימי |
| **בועה סביב בניין** | הבניין. **כחול (או צבע אחר)** = קבוצת בניינים שמחוברים ביניהם מבפנים (לפי OSM או טקסט רשמי של שיבא). **אפור מקווקו עם ⛔** = אין מעבר פנימי ידוע לאף בניין אחר |

> "אין מעבר ידוע" אינו "אין מעבר". זה רק מה שכתוב ב-OSM ובאתר שיבא. אם אתה יודע על מעבר – הוסף אותו ב-`data/topology-seed.json` (ראה למטה).

הקבוצה הגדולה כרגע: מגדל האשפוז + מרכז הסרטן + החניון המרכזי/מרכז הצומת + מיון + ספרא + מכון פה ולסת + אגף המעבדות + בנק הדם
(מסדרון הקרקע הארוך שממופה ב-OSM מחבר מיון ← מגדל ← מרכז הסרטן; מקומה 4 בחניון יש מעבר למגדל ולספרא לפי הוראות ההגעה הרשמיות).
כל השאר – מרכז הלב, עיניים, אא"ג, שיקום, פדה, נשים ויולדות, נפש, שי-לב ועוד – **עומדים לבד**.

## שליטה

* **גיאוגרפיה ↔ גרף**: מימין (גיאוגרפיה) הצמתים יושבים במיקום האמיתי; משמאל (גרף) הפנים של כל בניין מתפרס לפי אורך המסדרונות.
* **חיפוש** (למעלה): מרפאה, מעלית, קומה. לחיצה על תוצאה מזיזה ובוחרת.
* **סוגי צמתים / קווים**: לחיצה על שורה במקרא מסתירה/מציגה. תוכל להסתיר כבישים וחניות ולהישאר עם הפנים.
* **מתאר בניינים אמיתי (OSM)**: מראה את צורת הבניינים בפועל מאחורי הגרף.
* **גרירת צומת** נועלת אותו (מסגרת אדומה); לחיצה כפולה משחררת. **ארגון מחדש** משחרר הכול.
* **מסלול בין שני צמתים**: בחר צומת ← "קבע כמוצא", בחר אחר ← "קבע כיעד", **חשב**. אפשר לבקש בלי קישורים לא מאומתים, נגיש (בלי מדרגות), או רק בפנים.
* בכל צומת בפרטים: מקור המידע, רמת ביטחון, ודרגת החשיבות, וקישור "חיפוש במפות גוגל" (ידני – ראה למטה).

## מאיפה המידע (ומה לא)

| שכבה | מקור | הערות |
|---|---|---|
| בניינים, כניסות, מסדרונות פנימיים, כבישים ושבילים, חניות | OpenStreetMap | משקלים נמדדים |
| קומות, מעליות, לובי, עמדת מודיעין, אגפי מרפאות חוץ, מעברים מהחניון | הטקסט של "איך מגיעים" באתר שיבא (`data/topology-seed.json`, עם `src` לכל צומת וקו) | **המשקלים משוערים** |
| ~500 מרפאות | לובי המרפאות + הטקסט "מיקום" בדף כל מרפאה (`data/clinics-directory.json`) | רק שם, קישור ומיקום; בלי טלפונים/מיילים |
| בדיקות (248 דפים) | sitemap של האתר | דף בדיקה לא מציין מיקום – ראה `docs/CLINICS-COVERAGE.md` |

**גוגל מפות לא שימש כמקור.** תנאי השימוש שלו אוסרים חילוץ אוטומטי ושמירת התוכן, ובפרויקט משתמשים רק בחומר שמותר להשתמש בו שוב.
המיקומים נלקחו מהטקסט הרשמי של שיבא; למי שנשאר בלי מיקום יש קישור לחיפוש ידני במפות (ב-`docs/CLINICS-COVERAGE.md` ובפרטי הצומת).

## איך מתקנים / מוסיפים

1. ערוך את `data/topology-seed.json`:
   * צומת: `{ "id": "tower/F5/E", "label": "…", "kind": "hall|lobby|elevator|stairs|admin|room|clinic|other", "building": "tower", "floor": "5", "conf": "text", "src": "מאיפה זה" }`
   * קו: `{ "a": "tower/lobby", "b": "tower/info", "kind": "hallway", "sec": 8, "conf": "text", "src": "…" }` – `sec` בשניות; הוסף `"est": false` רק אם מדדת בפועל.
   * מעלית: צומת עם `"serves": ["0","2","5"]` ו-`"exits": {"5": "tower/F5/E"}` – הבילדר יוצר לבד את קווי "יציאה מקומה".
   * `conf`: `text` (מקור רשמי) · `osm` · `inferred` (לא מאומת – לא יחבר בניינים לקבוצה אחת).
2. `npm run build:topology` – בונה מחדש את `data/topology.json` (ואת `topology.graphml`), מחשב חשיבות וקבוצות.
3. רענן את הדף. `npm test` בודק שאין קווים תלויים, שהקבוצות הגיוניות ושהערכות מסומנות.

## קבצים

* `data/topology.json` – הגרף (נבנה). `data/topology.graphml` – אותו גרף לפורמט GraphML (נפתח ב-yEd / Gephi / NetworkX).
* `data/topology-seed.json` – המבנה הפנימי בכתב יד. `data/clinics-directory.json` – המרפאות.
* `tools/build-topology.mjs`, `tools/build-directory.mjs`, `tools/crawl/*` – הבנייה והאיסוף (`npm run crawl:lobby && npm run crawl:clinics && npm run build:directory`; דורש Playwright).
